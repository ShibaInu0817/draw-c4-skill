Getting one

Ask, and get two files

  1. Ask in your own words

    "Diagram this codebase", "how does a request flow through this?", or /draw-c4. It asks which flows and levels you want.

  2. It reads the code

    Compose files, modules, queues and handlers, not the README. Anything it cannot trace is left out.

  3. You get two files

    architecture.html to open and share, and model.json to update it next time.

# what Claude runs for you
python3 plot.py layout model.json --all
python3 plot.py check  model.json
python3 plot.py build  model.json architecture.html

Before you install

Questions

Can I trust what it draws?

Every box is meant to trace back to a file, a config entry or a route handler. check catches a dangling reference or two overlapping boxes, but not a wrong claim. Read a new diagram before you rely on it.

What do I need installed?

Claude Code and Python 3. The scripts use the standard library only, so there is nothing to pip install.

How do I update a diagram after the code changes?

Ask Claude to refresh it. It reads the model back out of the HTML, edits it, keeps your layout and places the new parts.

Can I share the result?

Yes. It is one HTML file with no server and no build step. Commit it, send it, or open it from disk.
