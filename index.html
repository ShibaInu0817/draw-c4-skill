Open any part

Start at the containers and double-click into the ones with something inside. Up to four levels.

Play a request

Flows are grouped by area. Each step lights one line and says what the code does there, failures included.

Ask what a part does

The inspector lists what each part talks to and who calls it, read from the real code.

Ask

"Diagram this codebase." The skill asks which flows and levels you want.

It reads the code

Compose files, modules, queues and handlers, not the README.

You get two files

architecture.html to open and share, and model.json to update it next time.
